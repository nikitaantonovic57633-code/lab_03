# Лабораторная работа №3. Каталог объектов

## Описание
Проект представляет собой каталог книг, реализованный на Python с использованием `dataclass`.


Каталог позволяет добавлять, получать, удалять и искать книги, а также сохранять данные в JSON-файл и загружать их 
обратно.

## Возможности
* Создание книг с проверкой корректности данных
* Добавление книг с уникальными идентификаторами
* Получение и удаление книг по идентификатору
* Поиск книг по категории  
* Поиск книг по названию без учёта регистра
* Получение количества книг в каталоге
* Перебор книг в порядке добавления
* Проверка наличия книги по идентификатору
* Сохранение и загрузка каталога в формате JSON
* Обработка ошибок с помощью пользовательских исключений

## Модель книги
Класс `Book` реализован с помощью `@dataclass` и содержит следующие поля:


| Поле | Тип | Описание |
| :---: | :---: | :--- |
| book_id | str | Уникальный идентификатор книги|
| name | str | Название книги |
| category | str | Категория книги |
| year | int | Год издания |
| author | str | Автор книги |
| pages | int | Количество страниц |


При создании книги проверяются корректность типов и значений полей.  
Строковые поля не могут быть пустыми или состоять только из пробелов.  
Год издания должен находиться в диапазоне от 1 до текущего года, а количество страниц должно быть 
положительным целым числом.  
При нарушении инвариантов возникает `InvalidBookError`.

## Работа каталога
Класс `Catalog` хранит книги в словаре, где ключом является `book_id`. Реализованы следующие методы:


| Метод | Назначение |
| :--- | :--- |
| add(item) | Добавление книги |
| get(item_id) | Получение книги по ID |
| remove(item_id) | Удаление книги по ID |
| find_by_category(category) | Поиск книги по категории |
| find_by_name(query) | Поиск книги по названию |
| len(catalog) | Получение количества книг |
| iter(catalog) | Перебор книг |
| item_id in catalog | Проверка наличия ID |


Поиск по ID выполняется через словарь.  
Поиск по категории и названию перебирает книги каталога.  
Поиск по названию выполняется по полному совпадению без учёта регистра, а поиск по категории учитывает регистр.  
При итерации книги возвращаются в порядке их добавления. Если удалить книгу и добавить её заново, она окажется в конце 
последовательности.  
Методы поиска возвращают новые списки, а не внутреннюю коллекцию каталога.

## Сохранение и загрузка
Для хранения каталога используется JSON с версией формата 1.  
Функция `save_catalog()` сохраняет каталог в JSON-файл.  
Функция `load_catalog()` создаёт новый каталог из данных JSON-файла. При ошибке загрузки частично сформированный каталог 
не возвращается, а существующие каталоги не изменяются.

## Исключения
В проекте реализована иерархия пользовательских исключений с базовым классом `CatalogError`:
* `InvalidBookError` - некорректные данные книги
* `DuplicateIDError` - повторяющийся идентификатор книги
* `BookNotFoundError` - книга с указанным идентификатором не найдена
* `UnsupportedFormatVersionError` - неподдерживаемая версия формата JSON
* `CorruptedFileError` - повреждённый JSON или некорректная структура файла
